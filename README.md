# Chaînes francophones pour Kodi

Liste de chaînes TV et de radios gratuites et légales, avec leur guide des programmes, utilisée par les appareils Kodi de la maison.

| Fichier | Rôle |
|---|---|
| `playlist.m3u` | La liste des chaînes et radios, lue par l'extension IPTV Simple Client |
| `guide.xml.gz` | Le guide des programmes, régénéré chaque nuit à 3 h (heure d'Abidjan) |
| `custom.channels.xml` | Les sources du guide, chaîne par chaîne |

## Dans Kodi (IPTV Simple Client)

- **Liste M3U**, chemin distant : `https://raw.githubusercontent.com/kanga74/kodi-chaines-fr/main/playlist.m3u`
- **Guide (XMLTV)**, chemin distant : `https://raw.githubusercontent.com/kanga74/kodi-chaines-fr/main/guide.xml.gz`

Toute modification de `playlist.m3u` sur GitHub arrive sur les appareils au prochain démarrage de Kodi.

## Mettre le guide à jour tout de suite

Onglet **Actions** → **Guide des programmes** → **Run workflow**.
